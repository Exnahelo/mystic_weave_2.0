# Mystic Weave — Difficulty Reference

This reference standardizes challenge calibration for narration and `POST /roll` target assembly. Use with `prompts/world-rules.md` and `prompts/engine.md`.

## Canonical Difficulty Ladder

| Difficulty | Modifier | Meaning |
|---|---:|---|
| Trivial | +20 | Nearly certain unless disrupted |
| Easy | +15 | Routine for prepared characters |
| Standard | +10 | Baseline adventuring challenge |
| Hard | +5 | Meaningful pressure; mistakes matter |
| Severe | +0 | High-stakes challenge with clear risk |
| Extreme | -10 | Borderline capability; strong cost risk |
| Legendary | -20 | Exceptional, campaign-defining feat |

## Calibration Rules

1. Start from fiction: what is the primary failure risk?
2. Set base difficulty from the table below.
3. Apply only one final difficulty modifier (do not stack multiple difficulty tiers).
4. If multiple tiers seem valid, choose the harder tier.
5. If uncertainty remains, use **Standard (+10)** as fallback.

## Fast Adjusters (Narrative-Only Guidance)

Use these to choose the single final tier, not as arithmetic stacking:
- **Preparation advantage:** likely one tier easier
- **Time pressure / surprise:** likely one tier harder
- **Hostile environment:** likely one tier harder
- **Strong leverage/tools/intel:** may offset one harder factor

When factors conflict, prefer conservative adjudication and preserve continuity.
