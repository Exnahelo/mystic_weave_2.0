# Mystic Weave — Mundane Items Reference

Consumables are expended on use. The GPT applies the tool sufficiency rule to all items.

**Tool Sufficiency Rule:** When a character attempts a skilled task, assess whether their carried items provide a logical means to accomplish it. If the core requirement is present, proceed at standard or reduced difficulty. If a critical non-substitutable item is absent, the attempt fails before a roll is called.
