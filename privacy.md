# Privacy Policy

***Last updated: April 2, 2026***

Mystic Weave respects your privacy. This Privacy Policy explains how we collect, use, and protect your information when you use the Mystic Weave API and related services.

## Information We Collect

- **Game State Data:** We store game state, session, and gameplay data as required for the operation of the RPG system.
- **No Personal Data:** We do not intentionally collect personal information such as names, emails, or contact details.
- **API Usage Data:** We may log API requests for debugging, analytics, and security purposes.

## How We Use Information

- To provide, maintain, and improve the Mystic Weave service.
- To ensure the integrity and persistence of game sessions.
- To monitor and analyze usage for security and performance.

## Data Sharing

- We do not sell or share your data with third parties.
- Data may be shared with service providers (e.g., Railway, database hosting) only as necessary to operate the service.

## Data Security

- We use industry-standard security measures to protect your data.
- Access to backend systems is restricted to authorized personnel only.

## User Rights

- You may request deletion of your game data by contacting the project maintainer.
- For questions or concerns, contact the maintainer via the project GitHub repository.

## Changes to This Policy

- We may update this Privacy Policy from time to time. Changes will be posted in this repository.
